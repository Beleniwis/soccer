# Soccer

## Problemática

Tenemos un catálogo de Ligas de Soccer, y un catálogo de Equipos. Los equipos se pueden inscribir a diferentes Ligas, y las Ligas pueden tener diferentes equipos. Hay algunas restricciones:
-Un equipo no puede tener menos de 11 jugadores ni más de 22 jugadores registrados.
-Las fechas de inicio y fin de la Liga deben de ser reales (no puede ser la fecha de inicio mayor a la fecha final de la liga).
-Por defecto el campo enabled debe de estar en 1, y por defecto las fechas de las ligas toman la fecha actual del registro.
-Ningún campo debe de ser nulo.
-Relaciona la tabla de Equipos con la tabla de Ligas de muchos a muchos.
-Valida los nombres (no pueden tener menos de 2 letras), tanto para ligas, equipos y países.

El proyecto utiliza una arquitectura basada en la comunicación entre un frontend desarrollado en Angular y un backend desarrollado con ASP.NET Core Web API.
